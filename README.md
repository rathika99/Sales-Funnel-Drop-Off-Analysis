# Sales Funnel Drop-Off Analysis

## Project Overview
The Sales Funnel Drop-Off Analysis project focuses on understanding customer behavior throughout the e-commerce purchasing journey. The objective is to identify customer drop-off points, analyze conversion performance, and provide actionable business insights using PostgreSQL and Power BI.

## Problem Statement
Many customers visit an e-commerce platform but leave before completing a purchase. Businesses often struggle to identify where customers drop off in the sales funnel. This project analyzes customer activities, cart behavior, payment performance, and conversion rates to identify opportunities for improving the customer journey.

## Objectives
- Analyze customer behavior across the sales funnel.
- Identify major customer drop-off stages.
- Analyze traffic sources, device types, and customer segments.
- Evaluate payment performance and cart abandonment.
- Compare A/B test conversion performance.
- Provide actionable business recommendations.

## Tools Used
- PostgreSQL – Data analysis and SQL queries
- Power BI – Dashboard development and visualization
- Microsoft Excel – Data preparation
- Power Query – Data cleaning and transformation
- DAX – KPI calculations

## Dataset
The project uses six tables:

1. Customer
2. Products
3. Customer Activity
4. Cart
5. Orders
6. AB Test

## Dashboard Pages

### Page 1 – Customer Funnel Analysis
Analyzes customer behavior, funnel stages, traffic sources, device usage, product category engagement, and customer types.

### Page 2 – Business Performance
Analyzes payment status, cart status, A/B test performance, revenue trends, and order trends.

### Page 3 – Executive Summary & Insights
Presents key findings, business insights, and recommendations for improving customer conversion and overall business performance.

## Key Findings
- Organic traffic generated the highest visitor volume.
- Mobile users contributed a significant share of website traffic.
- The New Checkout version achieved better conversion performance.
- Successful payments outnumbered failed payments.
- Cart abandonment was a major drop-off point.
- Returning customers showed stronger engagement.

## Recommendations
- Improve the checkout process to reduce customer drop-offs.
- Optimize the mobile shopping experience.
- Investigate reasons for cart abandonment.
- Improve payment reliability.
- Continue evaluating checkout versions through A/B testing.
- Develop targeted strategies for new and returning customers.

## Conclusion
The project provides a structured analysis of customer behavior and business performance through SQL and Power BI. The dashboard helps identify funnel drop-off points and provides actionable insights to improve conversion rates, reduce cart abandonment, and support data-driven decision-making.
